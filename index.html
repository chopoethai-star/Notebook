Google Sheet ချိတ်ဆက်မှု ဆက်တင်

Google Apps Script မှ ရရှိလာသော Web App URL ကို အောက်တွင် ထည့်သွင်းပေးပါ။

⚠️ ချိတ်ဆက်ပုံအကျဉ်းချုပ်:
  1. Google Sheet တစ်ခုဆောက်ပြီး ခေါင်းစဉ် (ID, Date, Title, Amount, Type, Category) သတ်မှတ်ပါ။
  2. Extensions -> Apps Script တွင် သတ်မှတ်ကုဒ်ထည့်ပါ။
  3. Deploy -> New deployment တွင် Web App (Execute as: Me, Access: Anyone) ရွေးချယ်ပြီး Deploy လုပ်ပါ။
  4. ရရှိလာသော URL ကို အပေါ်ကကွက်လပ်တွင် ဖြည့်စွက်ပါ။

စာရင်းအားလုံး ဖျက်ပစ်မလား။

ဤလုပ်ဆောင်ချက်သည် သင့်ဖုန်းထဲရှိ မှတ်တမ်းအချက်အလက်အားလုံးကို အပြီးသတ် ဖျက်ပစ်မည်ဖြစ်ပါသည်။ (Google Sheets ပေါ်ရှိဒေတာများကို မထိခိုက်ပါ)
